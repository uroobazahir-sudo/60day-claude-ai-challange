Day 5 – Prompt A vs Prompt B Comparison

Overview

This task explores the importance of context in Prompt Engineering by comparing two prompts that generate a 30-day learning roadmap.

- Prompt A: Generated without context.
- Prompt B: Generated with detailed context about the learner's background, goals, skills, and learning preferences.

The objective was to analyze how context affects the quality, relevance, and personalization of AI-generated outputs.

Key Findings

Prompt A (Without Context)

- Produces a generic roadmap.
- Suitable for a broad audience.
- Lacks personalization.
- Makes assumptions about the learner.

Prompt B (With Context)

- Produces a personalized roadmap.
- Aligns with specific goals and skill levels.
- Creates realistic and actionable learning plans.
- Provides more relevant recommendations.

Comparison Results

Which roadmap feels more personalized?

Prompt B

Which roadmap would be easier to follow?

Prompt B

What role did context play?

Context helped the AI understand the learner's situation, goals, available time, and experience level. As a result, the roadmap became more practical, targeted, and useful.

Key Insight

«Better Context = Better Output»

The more relevant information provided to AI, the more accurate, personalized, and actionable the generated response becomes.

Conclusion

This exercise demonstrated that context is one of the most important elements in Prompt Engineering. A well-structured prompt with relevant details can significantly improve the quality and usefulness of AI-generated results.
